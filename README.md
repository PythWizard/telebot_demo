# Telegram AI Assistant

Showcase version of a Python-based AI assistant integrating OpenAI API and Telethon for intelligent conversations, voice processing, and automated messaging workflows.

This project demonstrates the integration of Large Language Models (LLM) with Telegram automation, including context-aware conversations, speech recognition, and desktop-based configuration.

## Features

- 🤖 AI-generated responses using OpenAI API
- 💬 Context-aware dialogue management
- 🎤 Voice message transcription using Whisper
- ⏳ Automated follow-up communication scenarios
- ⌨️ Human-like typing simulation
- 🖥️ Desktop GUI interface built with Tkinter
- ⚙️ Configurable assistant behavior and prompts
- 📋 Telegram dialog history processing
- 📝 Application event logging

## Architecture

The application consists of several key components:

### Telegram Integration

- Telegram API communication using Telethon
- Incoming message processing
- Automated response delivery

### AI Processing

- OpenAI API integration
- Context-aware response generation
- Custom system prompts and assistant behavior configuration

### Speech Recognition

- Voice message downloading
- Audio transcription using faster-whisper

### Automation Engine

- Follow-up message scheduler
- User activity tracking
- Scenario-based communication workflows

### Desktop Interface

- Tkinter-based GUI
- Runtime configuration management
- Application monitoring and logging
